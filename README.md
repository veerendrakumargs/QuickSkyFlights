\# ✈️ QuickSky Flights



A Django-based flight search and booking web application designed to simplify the flight booking experience.



\## 🚀 Project Overview



QuickSky Flights is a web application that allows users to explore available flights and manage their flight bookings through a web interface.



\## ✨ Features



\- Flight search functionality

\- User authentication

\- Flight booking system

\- Passenger details management

\- PNR generation

\- Seat availability management

\- Booking confirmation



\## 🛠️ Technologies Used



\- \*\*Backend:\*\* Python, Django

\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*Database:\*\* SQLite

\- \*\*Version Control:\*\* Git and GitHub

\## ⚙️ Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/veerendrakumargs/QuickSkyFlights.git

cd QuickSkyFlights

```



\### 2. Create a virtual environment



```bash

python -m venv myenv

```



\### 3. Activate the environment



Windows:



```bash

myenv\\Scripts\\activate

```



\### 4. Install dependencies



```bash

pip install -r requirements.txt

```



\### 5. Apply migrations



```bash

python manage.py migrate

```



\### 6. Start the development server



```bash

python manage.py runserver

```



Open http://127.0.0.1:8000/ in your browser.
